## Current Projects

* [RISC-V Data Kit](https://github.com/drewv-labs/riscv-data-kit) (`WIP`): Bare-metal Day-0 bootstrap, kernel tuning, and hardware telemetry toolkit for RISC-V data engineering and Edge ML nodes (SiFive, StarFive, Milk-V).

* [BrakerRak](https://github.com/drewv-labs/brakerrak) (`WIP`): Bare-metal RISC-V Data Engineering & Edge ML research rack: PostgreSQL 18 io_uring brokers, 4Kn NVMe, Btrfs RAID10, and CTD telemetry.

* [CarrierPigeons](https://github.com/drewv-labs/carrierpigeons) (`WIP`): Go-powered Continuous Telemetric Documentation (CTD) and distributed execution harness for RISC-V, ARM64 & x86_64 edge compute, data engineering, and ML workloads.

* [AdaLovespace](https://github.com/drewv-labs/adalovespace) (`WIP`): Distributed RISC-V & Hailo-8 (26 TOPS) Edge ML astrophotography cluster with real-time FITS triage, edge data brokering, and CTD telemetry.
